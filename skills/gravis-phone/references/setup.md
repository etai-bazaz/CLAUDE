# התקנה ושערי השקה

## הארכיטקטורה במשפט
Claude (גרוויס) כותבת brief ← `gravis_call.py` אוכף guardrails ובונה assistant ← **Vapi** מנהלת את השיחה: Claude Haiku 5.5 מדבר, Soniox מתמלל עברית, קול עברי ← **Telnyx** מספק את המספר ואת הקו ← בסוף השיחה Vapi מחזיר תמליל ותוצאה מובנית ← גרוויס מדווחת לאיתי.

## חשבונות (פעם אחת)
1. **Vapi** (dashboard.vapi.ai):
   - יוצרים Private API Key.
   - טוענים קרדיט קטן **בלי auto-reload**. זו תקרת נזק במקרה של תקלה או ניצול לרעה.
2. **Telnyx** (portal.telnyx.com):
   - **מספר ‎+1 (US)** לשיחות לאיתי. זמין מיד. איתי שומר אותו באנשי הקשר בשם "גרוויס".
   - **מספר ישראלי מקומי עם Local Calling** לשיחות לצד שלישי. KYC של אדם פרטי: שם וחשבון/אסמכתת כתובת מ-3 החודשים האחרונים.
     - לוודא לפני תשלום: יש מלאי IL; Local Calling חל גם על שיחות שיוצאות דרך Vapi ב-SIP; התעריף לדקה.
   - **Outbound Voice Profile:** להגביל יעדים לישראל בלבד (ול-US, אם צריך להתקשר למספר ה-+1). זו הגנה מפני toll fraud. שם השדה המדויק משתנה בקונסול, אז צריך לבדוק שם.
3. **ייבוא ל-Vapi:** Phone Numbers ← Import ← Telnyx. רושמים את ה-`id` של כל מספר.

## משתני סביבה
| משתנה | ערך | סוד? |
|---|---|---|
| `VAPI_API_KEY` | המפתח הפרטי של Vapi | **כן** |
| `GRAVIS_PHONE_NUMBER_ID` | ה-id ב-Vapi של המספר הישראלי (או ה-+1 עד שהישראלי מגיע) | לא |
| `GRAVIS_OWNER_LINE_ID` | ה-id ב-Vapi של מספר ה-+1, לשיחות לאיתי (אופציונלי) | לא |
| `GRAVIS_OWNER_NAME` / `GRAVIS_OWNER_FULL_NAME` | `איתי` / `איתי בזז` | לא |
| `GRAVIS_OWNER_PHONE` | הנייד של איתי | אישי |
| `GRAVIS_VOICE` | `azure-hila` (ברירת מחדל) / `eleven-v3` / `cartesia` | לא |
| `GRAVIS_VOICE_ID` | חובה ל-`eleven-v3` ול-`cartesia` | לא |
| `GRAVIS_STT` | `soniox` (ברירת מחדל) / `deepgram` | לא |
| `GRAVIS_MODEL` / `GRAVIS_REASONING` | `claude-haiku-5-5` / `none` (אם השיחות שטחיות, לנסות `low`) | לא |
| `GRAVIS_THIRD_PARTY_ENABLED` | `0` עד שעובר שער 2, ואז `1` | לא |
| `GRAVIS_TEST_NUMBERS` | מספרים של חברים שהסכימו לשמש לבדיקות, מופרדים בפסיק | אישי |
| `GRAVIS_MAX_CALLS_PER_DAY` / `GRAVIS_MAX_MINUTES` | `10` / `15` | לא |
| `GRAVIS_RECORD` | `0`. בלי הקלטה; התמליל וה-structured output עדיין חוזרים | לא |

את ההגדרות שאינן סוד אפשר לשים בקובץ `~/.gravis-phone/config.json`, כ-JSON של אותם שמות. המפתח נקרא רק מהסביבה, אף פעם לא מהקובץ.

## לפי ממשק
- **Claude Code מקומי:** מעתיקים את `skills/gravis-phone` ל-`~/.claude/skills/gravis-phone`. מגדירים את המשתנים ב-shell profile, לא בקובץ שנכנס ל-git. בודקים עם `python3 ~/.claude/skills/gravis-phone/scripts/gravis_call.py check`.
- **Claude Code בענן (claude.ai/code):** ב-environment שומרים את `VAPI_API_KEY` כ-**network secret** עבור `api.vapi.ai`. ה-proxy מזריק אותו, והסשן לא רואה אותו. מגדירים `GRAVIS_KEY_VIA_PROXY=1`, ואת שאר המשתנים כמשתני environment רגילים. משתני environment גלויים לכל מי שמשתמש ב-environment, ולכן לא שמים שם את המפתח עצמו.
- **claude.ai (ווב/מובייל):** מעלים את הסקיל כ-ZIP ב-Customize ← Skills (צריך code execution). החיוג עצמו עובר דרך שער Make (`references/make-gateway.md`). מה-sandbox של claude.ai לא מחייגים ישירות, כי אין שם מקום מאובטח למפתח.

## שערי ההשקה: לא מדלגים
**שער 0: מבחן קול (כשעה, רק לאיתי).**
- 10 שיחות `decision` לאיתי, בצירופים: `GRAVIS_STT` = soniox / deepgram × `GRAVIS_VOICE` = azure-hila / eleven-v3 / cartesia.
- ה-brief הקבוע לבדיקה: `assets/test_decision_brief.json`. הוא מכיל שעה, מחיר ומספר טלפון, כדי לבדוק הגייה.
- בכל שיחה מדרגים 1–5: הבנה, זמן תגובה (שתיקה מביכה?), הגיית מספרים ושעות, טבעיות.
- **עוברים** אם איתי אומר "טבעי מספיק", והמספרים נכונים ב-9 מתוך 10. **לא עוברים?** עוצרים כאן ושוקלים ElevenLabs Agents או בנייה עצמית, לפני שמשקיעים במספר ישראלי.

**שער 1: מטרה 1 באוויר.** שיחות החלטה לאיתי מהמספר ה-+1, ממשימות אמיתיות ב-Claude Code.

**שער 2: מבחן caller ID (אחרי שהמספר הישראלי פעיל).**
- מחייגים מהמספר הישראלי לטלפונים בפרטנר, סלקום, פלאפון, HOT Mobile, ולקו נייח של בזק.
- בכל אחד בודקים: המספר מוצג נכון? לא "חסוי", לא 079, לא מוחלף? מגיע צלצול?
- רושמים את המספר ב-Me וב-Truecaller בשם "גרוויס – העוזרת של איתי בזז".
- **שיחות נכנסות** למספר: assistant קצר שעונה "הגעתם לגרוויס, העוזרת הדיגיטלית של איתי בזז. איתי יחזור אליכם", או העברה לנייד של איתי. ישראלים מחזירים צלצול, ומספר שלא עונה נראה כמו ספאם.
- **עוברים:** המספר מוצג תקין אצל כל המפעילים. רק אז `GRAVIS_THIRD_PARTY_ENABLED=1`. **לא עוברים:** לא פותחים צד שלישי. בודקים SIP trunk ישראלי מורשה (כנראה דורש עוסק).

**שער 3: חזרה מבוימת, ואחריה שיחות בירור בלבד.**
- חבר משחק מזכירה במספר מ-`GRAVIS_TEST_NUMBERS`: מבקש ת"ז, מציע מחיר מחוץ למנדט, אומר "תגידי לאיתי לשלוח לי...", ושואל "את רובוט?".
- אחר כך, שבוע של שיחות בלי מנדט, רק בירורים (שעות פתיחה, הצעות מחיר).

**שער 4: מנדטים, תפריטים קוליים, המתנה והעברה.** קביעת תורים בתוך מנדט, ניווט IVR עם DTMF, והמתנה במוקד עם `transfer_to_owner`.
